Conheça o projeto

Dados claros para melhorar sua partida na selva

O JungleGG reúne estatísticas de partidas ranqueadas de alto elo para ajudar jogadores a comparar campeões, builds, runas, rotas e situações de confronto.

O projeto

Uma referência feita para a rota da selva

O objetivo é transformar dados brutos em informações fáceis de consultar. As estatísticas mostram tendências observadas em partidas reais, não regras absolutas nem uma promessa de vitória.

01

Dados das partidas

Win rate, escolha, banimento, builds, runas, confrontos e mapas são calculados a partir das partidas coletadas da API oficial da Riot Games.

02

Amostras responsáveis

Taxas de vitória aparecem apenas com amostra suficiente. Quando os dados são baixos ou inexistentes, o projeto deixa isso explícito em vez de fingir precisão.

03

Atualização automática

Um coletor atualiza periodicamente o arquivo de estatísticas. Informações antigas continuam disponíveis caso o serviço da Riot fique temporariamente indisponível.
